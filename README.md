### O aplikaci
**AppLayout** vám dává plnou kontrolu nad pracovní plochou. Umožňuje zafixovat velikosti a pozice oken libovolných programů na monitoru a automaticky je otevírat přesně tam, kde je chcete mít.

#### Klíčové funkce
- **Přesné ukotvení oken:** Uložení souřadnic a velikostí oken s možností jejich okamžitého vyvolání.
- **Spouštěcí parametry:** Možnost automatického startu programů se specifickými argumenty (např. otevření konkrétní URL adresy v prohlížeči).
- **Rychlý a úsporný:** Běží nenápadně na pozadí s minimálním využitím systémových prostředků.
- **Bez nutnosti instalace složitých balíčků:** Připraveno ihned k použití.

#### Stažení a spuštění

2. Spusťte soubor ve Windows a nastavte si své pracovní profily.

### About
**AppLayout** gives you complete control over your Windows workspace. It anchors application windows to custom screen coordinates, automating window arrangements for daily productivity.

#### Highlights
- **Layout Memory:** Save and restore multi-window setups effortlessly.
- **Launch Arguments:** Trigger programs with specific flags (e.g. predefined web URLs).
- **Lightweight:** Low RAM/CPU footprint, runs quietly in the background.
